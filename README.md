# Halfshade — An Origins Addon

Полные исходники версии **1.0.5**, загруженной на CurseForge.

## Содержимое

- `src/main/java/ru/poluten/Poluten.java` — серверная логика способностей.
- `src/main/java/ru/poluten/PolutenClient.java` — чёрная и красная виньетка.
- `src/main/resources/` — JSON происхождения и способностей, текстуры и описание мода NeoForge.
- `build.gradle`, `settings.gradle`, `gradle.properties`, `gradlew*`, `gradle/wrapper/` — настройки сборки Gradle.
- `releases/` — оригинальный готовый JAR 1.0.5.
- `docs/` — значок, описание и данные выпуска CurseForge.
- `tools/generate_resources.py` — необязательный генератор ресурсов (Python 3, без сторонних библиотек). Перезаписывает ресурсы значениями из генератора; обычно редактируйте сами файлы в src.
- `tools/create-icon-original.ps1` — исходный скрипт создания значка, сохранённый для справки; он использует исходный путь outputs относительно текущей папки.
- `tests/integration/Checks.java` — исходник отдельного тестового мода, использованного для серверных проверок. Он не включается в обычный JAR.

## Сборка

Нужен JDK 21 и интернет для первой загрузки Gradle, Minecraft, NeoForge и зависимостей. При поддерживаемой конфигурации Java toolchain может загрузиться автоматически через Foojay.

Откройте терминал в этой папке и выполните:

```powershell
.\gradlew.bat build
```

Результат: `build/libs/poluten-1.0.5-neoforge-1.21.1.jar`.

Для запуска среды разработки: `.\gradlew.bat runClient`.

Gradle-конфигурация подготовлена при экспорте исходников; полная сборка именно через неё пока не выполнялась. Оригинальный JAR в releases был собран отдельно через javac с --release 21 и проверен в игре. Файлы src/main/resources сверены с содержимым этого JAR.

## Установка и совместимость

Minecraft 1.21.1, NeoForge 21.1.228 или новее в ветке 21.1, **Origins (NeoForge) строго 0.3 от IAFEnvoy**, Jupiter. Установка на клиент и сервер. Для сборки зафиксирован NeoForge 21.1.235.

Внутренний mod ID — `poluten`, происхождение — `poluten:poluten`. Не меняйте ID при переименовании проекта: это важно для сохранений.

В 1.0.5 отрисовка сохранена как в 1.0.3, а непрозрачность самой текстуры уменьшена вдвое.
