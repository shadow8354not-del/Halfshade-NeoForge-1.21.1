## Changelog

First public beta of Halfshade, an Origins addon for the NeoForge 0.3 port.

- Adds Shadow Form, Night Wind, Shadow Venom, Last Breath, and the origin's associated weaknesses.
- Includes a black shadow vignette that turns red when hunger approaches the form's cutoff.
- Uses a half-opacity vignette texture while retaining the rendering code from version 1.0.3, the version the author confirmed working with Shine.
- Includes a visible message when Shadow Venom successfully applies Wither.
